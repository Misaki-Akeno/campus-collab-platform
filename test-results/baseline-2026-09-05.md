## 明确阻塞与后续动作

1. Docker Desktop 4.68.0 在启动时崩溃。主机日志给出的直接原因是无法移除失效的运行时 socket `C:\Users\cxf21\AppData\Local\Docker\run\dockerInference`。尝试以普通用户启动服务也因服务控制权限不足而失败。本次没有执行 factory reset，也没有删除 Docker 数据卷。
2. 建议完全退出 Docker Desktop 后，仅清理上述失效的 `dockerInference` 运行时 socket，或先关闭 Docker AI/Inference 功能，再重启引擎。引擎恢复后依次执行 `docker compose up -d`、健康检查、Java 服务启动和 Bruno 集合。不要在没有备份的情况下使用 factory reset。
3. 根 POM 没有固定 `maven-compiler-plugin` 版本。Maven 3.9.16 会探测需要 Maven 4 的 4.0.0 beta 版本后再回退到兼容版本；目前不阻断，但会产生噪声并降低构建可复现性，建议在后续基础设施工作包中固定版本。
4. `requirements.txt` 同时固定旧版 Pydantic 并开放 LangChain 上界，Python 3.12 下解析不稳定。建议新增受控的运行/测试锁定文件或约束文件，并把 pytest、pytest-asyncio 及代理环境需要的可选依赖区分记录。
